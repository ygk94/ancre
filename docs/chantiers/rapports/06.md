## 2. Les scènes en fork (MESURÉ-FORK, 06/10)

Fork du testnet, vrais registres ERC-8004 v2.0.0 (`0x8004A818…`, `0x8004B663…`), vrai USDC, `AnchoredReputation` et
`TrustGatedPayer` du dépôt, facilitator x402 émulé comme x402-rs. Ensemble : 3 ancres « demo » (aucune n'est le wallet
d'un agent, AM-08.A), m = 2, q = 1, θ = 1 %, Registry-verified, soumetteur attesté (D27), maxAge = minRefresh. Ordre d'exécution : 0, 1, 7, 2, 3, 4, 5, 6.

| Scène | Ce qui est vérifié | Statuts observés |
|---|---|---|
| 0 mise en place | déploiements, ensemble (`computeSetId` = setId du certificateur), 2 fournisseurs, payeur, 1er certificat | — |
| 1 honnêtes | 2 vouches d'ancres chacun → payés | `OK`, trusted ; masse robuste 3,46 % et 3,95 % ; **PAID** ×2 |
| 7 2ᵉ saut (D50) | provider-1 (2 ancres) vouche provider-3, qu'aucune ancre n'a noté | masse **2,30 %** > θ, trusted, **PAID** ; une liste à un saut le dirait inconnu |
| 2 ferme | 10 agents, 20 vouches à 100 ; puis une **ancre compromise** vouche la cible | moyenne naïve **100**, masse **0**, `UNTRUSTED` ; après l'ancre : `trust > 0`, **`trustRobust = 0`**, refusé |
| 3 la ferme se paie (D45) | 5 paiements x402 internes, Transfer USDC relu dans chaque reçu | 5/5 reçus vrais, masse 0, refus maintenu |
| 4 disjoncteur | slash de anchor-B sur provider-2 | **`VETOED`, `ANCRE_STATUS` dès le paiement suivant** ; recertifié ; toujours refusé |
| 5 anti-effacement (D33) | `review +1` d'un noteur tiers | moyenne naïve 16,67 → 12,75 ; toujours `VETOED` |
| 6 certificat fabriqué | arête « anchor-A → cible » absente du registre | **`EdgeMismatch(2, 1)`** à la soumission (simulée) |

Chaque refus compté est **celui du contrat** : rejeté au `/verify`, avec `explain` différent de `OK` (AM-INT.2). Une panne du facilitator ou du RPC arrête le script ; elle ne compte jamais comme un refus.

**Latences (scène 4)**
- Le refus vaut **dès l'état qui contient le slash : 0 bloc après son inclusion** (fork, 27-46 ms d'horloge). Il n'attend aucun certificat, parce que le veto est lu en direct (`_lastFeedback`, D21/D33).
- Le certificat qui porte le bit de veto arrive 1 bloc plus tard.
- Les millisecondes du fork ne sont pas des chiffres Monad, puisqu'anvil mine instantanément. Les vraies latences ne se mesureront que sur le testnet.

## 6. Angles morts

| Id | Angle mort | Statut |
|---|---|---|
| **AM-06.1** | **Le mode keystore du certificateur du 04 est cassé avec Foundry ≥ 1.8.** `ETH_PASSWORD` y est un *chemin* de fichier, et `certifier.Signer` y place le mot de passe. Avec `--json`, cast écrit l'erreur sur stdout, d'où un message vide | contourné dans `demo/certify.py` (fichier 0600 temporaire) ; **INTERFACE pour le 04** |
| **AM-06.2** | `eth_estimateGas` du vrai testnet contre anvil : un écart supérieur à 10 % fait échouer une transaction, qui paie quand même sa limite | NON VÉRIFIÉ, à observer à la 1re exécution |
| **AM-06.3** | La règle de réserve Monad n'est pas émulée par anvil. Les attentes (3 blocs) sont codées d'après la doc et répétées sur un fork miné en continu, mais jamais confrontées au vrai consensus | à observer sur le testnet |
| **AM-06.4** | Reprise : un arrêt entre l'inclusion d'une transaction et l'écriture de l'état rejoue cette transaction (par exemple un agent « demo » en double) | documenté (RUNBOOK §3) |
| **AM-06.5** | L'état figé ne rejoue que les scènes répétées. Une lecture d'un slot distant non lu pendant la répétition vaut 0 hors réseau | documenté (`lib/freeze.ts`) |
| **AM-06.6** | La « moyenne naïve » est **notre** définition (moyenne brute de tous les avis) ; la formule de 8004scan n'est pas documentée | l'écran doit écrire « naive average » |
| **AM-06.7** | Une ferme créée par un seul owner, avec des wallets financés par un même compte, est triviale à repérer par provenance (AM-5.5). Ce que la démo montre en plus : même sans aucune heuristique de provenance, la masse reste 0 | à dire dans le pitch |
| **AM-06.8** | La clé de graine du testnet dérive tous les comptes : si elle fuit, toute la démo est compromise (sur le testnet, sans valeur) | keystore chiffré, à n'utiliser pour rien d'autre |
