## 3. Décisions et leurs raisons

| Décision | Raison |
|---|---|
| Seuls les agents **notés** sont des nœuds ; la copie de ligne ne va qu'à eux | Un agent non noté a une masse nulle, sa copie ne porterait rien (D20). Le graphe reste petit (wallets à 762 agents) |
| Déclarer **sPlus = somme positive vraie**, plutôt que B⁺ | Déclarer B⁺ seul ne permet pas de calculer la marge d'omission quand Σ < 10 000. Avec sPlus, e reste une borne correcte même avec des arêtes omises |
| Les arêtes **négatives ne sont jamais omises** ; une ligne de plus de 256 négatifs n'est pas certifiable | Aucune somme négative n'est déclarée : omettre un négatif rendrait la borne haute de méfiance fausse |
| **Chaque ligne d'agent engage sa source, même vide** | Sinon, une ligne vide non contestable effacerait les slashs d'un agent (`BadProof(7)` en v0) |
| **La chaîne fait foi**, le fichier d'état n'est qu'un cache | Seul moyen d'être sûr après un crash et face à un `addNodes` public (v0) |
| Règle de remplacement **vérifiée avant de payer**, lue sur la chaîne | Sur Monad, une transaction qui revert coûte toute sa gas limit |
| Marge de gas **7,5 %** | Recommandation de GAS.md. La dérive n'est pas mesurable sur un fork |
| **Pas de clé privée en ligne de commande** : keystore, mot de passe par l'environnement du processus fils | `cast --private-key` rendrait la clé visible dans `ps` |
| Un service **par ensemble**, configuré par un JSON versionné, `setId` dérivé par `computeSetId` | File de transactions, règle de remplacement et soumetteur attesté sont propres à chaque ensemble (question ouverte du brief) |
| Encodage **v0 ou v1** au choix, `NotEncodable` plutôt qu'une troncature silencieuse | Le seul contrat déployable aujourd'hui est R5 (v0) |
| Le surveillant n'audite que le **certificat courant** ; toute erreur est non fatale | Un certificat remplacé n'est plus prouvable (sa racine a disparu) ; un bot de surveillance ne doit jamais mourir |
| Code et docs techniques en anglais (FORMAT.md, docstrings) | Consigne de session. CLAUDE.md §2 dit « le reste en français » : c'est au pilote de trancher |

## 4. Angles morts

| Id | Angle mort | Statut |

| **AM-04.1** | **La règle de remplacement du contrat v0 bloque les mises à jour honnêtes d'un graphe qui grandit.** Plus d'arêtes, donc plus de E⁺ et un eEff plus grand. Avec `slackRefresh = 0`, il faut attendre `maxAge` (≈ 1 jour) ; avec un slack, `minRefresh`. Sous D26, e ne borne plus que la méfiance, donc « eNew ≤ eCur » n'a plus de sens pour la confiance (lien avec AM-5.16 : règle par masse) | pour 02 ; le service contourne en reportant (MESURÉ : report de 601 blocs) |
