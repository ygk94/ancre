## 2026-10-06 — E3 : format du journal d'événements (`demo/EVENTS.md`) — ✅ (format)

**Fait** : `demo/EVENTS.md`, format `ancre-demo-events-v1`, écrit **avant** les scènes, sur demande du pilote : **le 07 le lit directement dans ce worktree**.
- Fichiers : `demo/out/run-<ts>.jsonl` (append-only, pour le live), `run-<ts>.json` (réécrit atomiquement, pour le rejeu), `latest.json` (chemin fixe).
- **Complément du pilote intégré** : chaque événement qui concerne un agent porte un bloc `agent` à deux colonnes, lu au bloc de l'événement : `explorer` (nombre d'avis, révoqués, clients, **moyenne naïve**) et `contract` (`assess` complet : statut, `trusted`, masse `trustLow` contre `theta`, borne `e`, veto, tag déclencheur résolu). L'écran met à jour les deux colonnes sans requête supplémentaire.
- Blocs `payer` (décision, étape verify/settle, `Reason`, `explain`), `certificate` (miroir du journal du certificateur), `latency` (scène 4 : avis → certificat → refus, en blocs et en ms).

**Décisions**
- Grands entiers en chaînes décimales (WAD, USDC, gas) ; compagnons `…Pct` flottants pour l'affichage seulement.
- Moyenne naïve = **notre** définition (moyenne brute de `value/10^decimals`, tous tags, non révoqués, relue on-chain). La formule de 8004scan n'est pas documentée : l'écran doit écrire « naive average », pas « score 8004scan ».
- Les scènes de refus **signent quand même** (contournement de la garde douce) pour que le refus affiché soit celui du contrat (garde dure, D41/D48).
- Latences étiquetées `fork` / `frozen` / `testnet` : seules celles du testnet se citent comme chiffres Monad (anvil mine instantanément).

**INTERFACE** : aucune demande aux autres chantiers. Toute évolution du format changera la chaîne `format` et sera notée ici.
