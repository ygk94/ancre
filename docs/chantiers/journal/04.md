**Décisions techniques et raisons.**
- **Seuls les agents NOTÉS sont des nœuds** : un agent non noté n'a pas de masse (pas d'arête entrante, pas ancre), sa copie ne porterait rien (D20). Garde le graphe petit (wallets à 762 agents).
- **sPlus = somme positive VRAIE déclarée** (plutôt que B⁺) : déclarer B⁺ seul ne permet pas de calculer la marge d'omission quand Σ < 10 000. La marge d'omission rend e correct même avec des arêtes omises.
- **Négatifs jamais omis** (revue de code, point 1) : sans somme négative déclarée, une omission de négatif rendrait distrustUp faux. C'est une faute prouvable, pas une option honnête.
- **Chaque ligne d'agent engage sa source, même vide** (revue, point 2) : sinon un certificateur pourrait publier une ligne vide incontestable pour effacer les slashs d'un agent.
- **Pas de nœud-adresse en double pour une ancre** (revue, point 6) : R8 simplifié, moins de cas pour le port TS.
- Ordre des tags en cas d'égalité : ordre des code points (= UTF-8), à ne pas confondre avec la comparaison par défaut de JS (UTF-16). Seuls `decidingTag` et `feedbackIndex` changent.
- Langue : FORMAT.md et les docstrings sont en anglais, selon la consigne de session (« docs techniques en anglais »). La revue signale un écart avec CLAUDE.md §2 : le pilote tranche.
